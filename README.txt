英语重建计划 · CET-4 离线 PWA V1

部署：新建 GitHub 公开仓库，上传本文件夹内全部文件到仓库根目录，Settings → Pages → Deploy from a branch → main / (root)。等待 Pages 网址生效后用手机访问。

iPhone：使用 Safari 打开网址 → 分享 → 添加到主屏幕。
Android：使用 Chrome 打开网址 → 菜单 → 安装应用/添加到主屏幕。

首次打开需要联网加载并缓存文件；之后可离线访问。朗读使用设备自带语音合成，不同系统离线语音可用性不同。数据保存在本机浏览器，建议定期到“学习档案”导出 JSON 备份。

当前为初版学习原型：6 道长难句、4 道中译英、4 个作文步骤、2 篇阅读和 8 组词汇。不是完整四六级题库，也不包含官方听力录音或 AI 自动批改。
